# PL 图像链路升级

本轮源码已加入以下功能。仿真、时序和实板验收分别见 `reports/xsim_*.json`、
`reports/system_timing_values.json`、`reports/pl_upgrade_summary.json`；缺失报告代表该项尚未完成。
旧版性能记录不作为本版的上板证据。

## 图像链路

OV5640 → 跨时钟 FIFO → 原始帧 DMA 与 ROI 分块统计。
原始帧写入 DDR 完成后，PL 独立读取同帧 ROI，缩放分屏后写入独立画布，
完成全部 DDR 写响应后才交给显示 VDMA。下一原始帧的采集与上一帧缩放并行，
通过独立启动寄存器和独立源地址解耦，避免串行调度错过下一次帧起始。缩放模块不反压摄像头采集。
VDMA → PL 色度降噪 → 亮度与边缘增强 → 局部亮度映射 → 保色重建 → PL 文字 → HDMI。

实时画面不再由 ARM 逐帧缩放、拼接或复制。ARM 负责按键、自动对焦初始化、
每秒约 4 次小规模统计/映射参数更新及状态文字。
相机独立帧率、PL 渲染完成帧率、已观察到的画布显示切换次数与 HDMI 60Hz 刷新分别计数。

原始帧保存为 1280×720，支持冻结后继续平移和放大。
冻结源缓冲被锁定，只有冻结视野改变时才由 ARM 生成新的冻结画布。
三组采集缓冲和四组显示画布显式管理所有权；正在显示、等待显示和冻结源均不得覆盖。

## 算法

- 分屏 1X 使用 2×2 盒式低通缩小，左右来自同一帧、同一 ROI。
- 放大使用整数倍最近邻；当前尚未实现任意比例双线性缩放。冻结视图沿用软件双线性。
- COLOR 色度降噪使用因果 3×3 邻域，保留当前像素亮度，按亮度差和色差避开明显边界。
  它是空间降噪，未包含运动补偿或帧融合；不能保证消除所有时间闪烁。
- 提亮后以共同色度增益恢复颜色，先检查整个 RGB 三元组的色域，再统一压缩色度。
  中性灰不会被人为染色，极亮饱和颜色会受到色域上限限制。
- 局部映射采用源 ROI 的 8×6 分块均值；增益限制为 0.75～1.5，分块增益做空间与时间平滑，
  像素间按块中心双线性插值，最终局部修正限于 ±24，近黑和高光渐弱。
  这是分块 tone mapping，当前没有完整 CLAHE 的局部直方图与限幅重分布。
- BINARY 可选 15×15、31×31 局部均值减 C；窗口为因果窗口，边界窗口不完整时沿用回退阈值。
  尚未实现居中窗口或 Sauvola 方差阈值。

## 操作和启动

EC11 短按依次选择：BRIGHTNESS、SHARPNESS、DENOISE、CONTRAST、ALGORITHM、NOISE、
EDGE_VIEW、COLOR、LOCAL_TONE、WINDOW31、BINARY_C。旋转调值，长按恢复当前画质预设。
原有板载模式、冻结、分屏、自动/手动、缩放与方向键保持。

```bash
cd /home/xilinx/jupyter_notebooks/visual_aid_v4_light_arduino_20261028
sudo /usr/bin/python3 preflight.py
sudo /usr/bin/python3 run_board.py --stage live --pipeline pl --camera-fps 20 --mode color --quality-preset detail --no-distance --af continuous --io-confirmed --seconds 120 --report logs/pl_check.json
```

默认实时入口为 `--pipeline pl`。`--pipeline cpu` 保留上一版软件合成及颜色时域降噪，
便于同场景对照和回退；两种管线的降噪算法不同。
默认 `detail` 保留已恢复清晰的相机 ISP 参数，采用 DN=0、SH=4、NR=1、CT=0，
关闭额外亮度/色度平滑，降低边缘触发门限，保留弱对比笔画；保色、局部映射与大窗口仍可调节。
这是细节优先的选择，暗部噪声可能比强降噪预设明显；实际清晰度仍需用户同场景确认。
`balanced` 保留更强的 DN=6、SH=2、NR=6 降噪预设，适合优先减少彩点的场景。
`baseline` 不启用新增保色、局部映射、31×31 默认档或 PL 色度降噪。
光照传感器本轮停用，提亮由图像统计驱动，无需增加硬件。

默认 `--tone-profile stable`：保留自动曝光与自动增益，明确选择 50Hz 防频闪，
扩大相机曝光外层保持区间；提亮统计加入 3 级死区，启动后曲线每次更新最多变化 1 个亮度级，
近黑增益上限从 lowlight 的 5 倍降为 3 倍。局部增益从 1.0 起步，每次更新变化不超过 2/256。
这些措施限制参数引起的亮度跳变，不能保证消除 LED PWM 或输入像素本身的全部时间噪声。
海外 60Hz 光源需相应调整相机设置；本次验证针对用户的 50Hz 环境。

验收时先固定 COLOR 和场景，再分别检查彩色物体、阴影文字、移动手、冻结/缩放/平移。
比较颜色、暗部彩点、笔画、拖影与真实独立帧率。显示正常与图像改善需要实物观察，
不能只以寄存器可读、仿真通过或 AF 命令应答代替。

显示 VDMA 的帧指针采用双行 Gray 编码，本版按四缓冲区的八个编码解码，
使显示参数始终对应被读取的画布；编码依据
[AMD PG020 的帧指针表](https://docs.amd.com/r/en-US/pg020_axi_vdma/Frame-Pointers-Gray-Code-Outputs)。
