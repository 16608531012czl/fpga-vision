# 当前版本操作

## EC11 旋钮

短按并松开：选中下一个项目。旋转：增减当前数值。长按约一秒：恢复启动时画质预设的默认参数。
查看左上角 `EDIT` 行确认当前项目和数值；达到边界后数值不再继续增加或减小。

| 顺序 | EDIT 项目 | 含义与范围 |
| --- | --- | --- |
| 1 | BRIGHTNESS | 亮度补偿，-10～10 |
| 2 | SHARPNESS | 锐化强度，0～10 |
| 3 | DENOISE | 降噪强度，0～10，0关闭 |
| 4 | CONTRAST | 局部对比度，0～3 |
| 5 | ALGORITHM | OFF、USM、LAPLACIAN、GUIDED |
| 6 | NOISE | 锐化噪点抑制阈值，0～10 |
| 7 | EDGE VIEW | 边缘诊断画面，OFF/ON |
| 8 | COLOR | 提亮后色彩补偿，0～16 |
| 9 | LOCAL TONE | 局部明暗补偿，OFF/ON |
| 10 | WINDOW | 二值化窗口，15/31 |
| 11 | BINARY C | 二值化阈值偏移，0～32 |

最后一项后再次短按返回亮度。WINDOW 和 BINARY C 在二值化模式观察；原始画面部分不应用增强。
旋钮不启动或停止程序。长按恢复画质参数，不重置当前缩放、冻结或自动/手动状态。

## 板载与五向按键

| 输入 | 功能 |
| --- | --- |
| BTN0 | RAW→GRAY→INVERSE→BINARY→COLOR 循环（从当前模式前进） |
| BTN1 | 冻结/恢复画面 |
| BTN2 | 左右对比/全屏 |
| BTN3 | 自动/手动增强 |
| 五向上/下/左/右 | 移动查看区域，放大后更明显 |
| 五向中心 | 1×/2×/4×循环 |

AUTO 时使用图像统计和照度进行有界提亮；亮度旋钮仍可叠加补偿。
MANUAL 停用全局自动提亮曲线，亮度补偿及单独的局部补偿开关仍有效。
距离模块本版未验收，启动参数使用 `--no-distance`，保留光照功能。
