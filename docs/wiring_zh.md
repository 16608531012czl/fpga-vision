# V3 接线分配（以本文件为准）

摄像头使用 PYNQ 40 针 Raspberry Pi 接口，外设使用板上 Arduino 接口。
`D3` 表示 Arduino 丝印 3，不是 40 针接口的第 3 脚；`J3-9` 表示 J3 插座的第 9 脚。
下面是逻辑分配，不代表观察某一面的针脚排列；断电接线，先找 1 号标记。

光照模块与八针五向按键的彩色连线图见 [图示与逐线说明](diagrams/README_zh.md)。
图中将光照 GND 接 J7-2、ADDR 接 J3-7 的 GND，按键 COM 接 J7-3 的 GND，
利用板内共地避免同一插孔并插两根线；五路按键信号与传感器信号分配不变。

| 摄像头丝印 | 40 针物理脚 | FPGA |
| --- | --- | --- |
| 3V3 / GND | 1 / 6 | 电源/地 |
| D0 / D1 / D2 / D3 | 11 / 13 / 15 / 19 | U7 / V7 / U8 / V8 |
| D4 / D5 / D6 / D7 | 21 / 23 / 24 / 22 | V10 / W10 / F19 / F20 |
| VS / HREF / PCLK | 18 / 16 / 31 | Y7 / W6 / U18 |
| SCL / SDA | 32 / 36 | B20 / B19 |
| RST / PD | 38 / 40 | A20 / Y9 |
| NC | 不接 | - |

PCLK 为输入时钟，U18 同时与 PMOD A 共享，不要同时接其他设备。
摄像头输入供电为 3.3V；本软件不认定 RST/PD/SCCB 必然允许 3.3V IO，必须按实物资料确认。
需要转换时，低速控制线可以单独处理；不能把普通 BSS138 转换板用于 DVP/PCLK。
软件仅拉低或释放 SCL/SDA，不主动驱动高电平；上拉电压由外部电路决定。
默认增强版沿用此前同一模块原图出图版本的摄像头 SCL/SDA 内部弱上拉。
另提供 `visual_aid_v3_external_pullup.bit`，关闭这两路内部上拉，供外部上拉/电平接口使用。
该选择不替代实物 IO 容限确认，也不应套用于未经核对的其他 OV5640 模块。

| 其余模块 | 接口 |
| --- | --- |
| 两个传感器 SDA | Arduino J3-9，P16 |
| 两个传感器 SCL | Arduino J3-10，P15 |
| 兼容 3.3V 的模块供电 | Arduino J7-5 的 3V3 和 J7-2 的 GND |
| 五向上 / 下 / 左 / 右 / 中 | D3 / D4 / D5 / D6 / D7（J4-4 至 J4-8） |
| 无源五向开关 COM | GND；五路信号启用 3.3V 内部上拉 |
| BH1750 ADDR（若引出） | 接 GND，7 位地址 0x23 |
| VL53L0X | 7 位地址 0x29；VIN/VCC/2V8/XSHUT 的连接须按具体模块确认 |

五向开关必须为五个独立触点、共地型；VRx/VRy 模拟摇杆和单路电阻分压型不适用。
若开关带有供电/上拉电路，必须另外核对模块电路，不能直接当裸开关接。

## 已提供的八针五向导航模块

2026-10-16 用户提供的商品图显示八针：`COM、UP、DWN、LFT、RHT、MID、SET、RST`。
从引脚说明与 PCB 布线看，这是共用端机械按键板，可沿用本工程五路独立、按下接地的输入设计。
商品图存档：`hardware/five_way_module_reference.jpg`；实物接线按丝印核对，不依赖照片中上下朝向。

| 模块引脚 | PYNQ-Z2 连接 | 当前功能 |
| --- | --- | --- |
| COM | GND（可用 Arduino J7-2） | 公共端接地 |
| UP | Arduino D3（J4-4，V13） | ROI 向上移动 |
| DWN | Arduino D4（J4-5，V15） | ROI 向下移动 |
| LFT | Arduino D5（J4-6，T15） | ROI 向左移动 |
| RHT | Arduino D6（J4-7，R16） | ROI 向右移动 |
| MID | Arduino D7（J4-8，U17） | 中心按下，循环 1×/2×/4× 放大 |
| SET | 不接 | 额外独立按键，当前未使用 |
| RST | 不接 | 额外独立按键，当前未使用；不接开发板复位口 |

只接 COM 与五路信号，共六根线。该图所示无源模块不需要另接 3.3V/5V 电源或电平转换；
COM 不接电源正极。工程 XDC 已启用五路内部上拉，松开为高电平，按下接通 COM 后为低电平。
断电时可用万用表通断档核对：松开时相应信号与 COM 断开，按下时导通。
现有代码已包含同步、25ms 软件消抖和方向长按重复，本次只补充接线资料，不改 RTL 或功能映射。

## 板载按键与其余接线注意

板载 BTN0..3 已布线，映射 FPGA D19/D20/L20/L19，不需要外置功能键。
Arduino D0..2、D8..13 在本方案不接编码器、外置按键或补光驱动。
补光灯独立供电与手动控制；本工程没有 PWM 控制口。

建议摄像头线长 5～10cm；多模块共用电源/总线时使用 Y 型分线或接线端子，禁止硬塞接头。
OV5640 寄存器配置采用板载 24MHz 晶振，不额外从 FPGA 输出 XCLK。
当前 PCLK 输入时序按 84MHz、下降沿更新/上升沿采样建立，数据与同步信号先进入 IOB 寄存器。
线缆/模块传播延迟未实测，输入延迟仍是初始预算，不能视为信号完整性已通过。

PYNQ 引脚依据厂家参考手册 v1.1（修订了早期 Raspberry Pi 映射），并与本机 PYNQ 2.4 XDC 交叉核对。
机器可读映射为 `pins.json`；软件测试检查同一 FPGA 管脚未被重复分配。
