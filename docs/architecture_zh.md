# 数据路径与证据边界

OV5640 RGB565 字节流 → DVP 校验/Gray 指针跨时钟 FIFO → 自定义 AXI 写入 DDR →
ARM 同一源帧 ROI/缩放/双份画布 → HDMI MM2S VDMA → FPGA 阅读增强 → 官方 HDMI OUT。

新系统不包含旧工程的 MicroBlaze IOP、USB 摄像头入口、HDMI 输入或不再使用的外设。
复用了官方 PS7/DDR 配置与 HDMI OUT 层级、已导出的两个 HLS IP 和 Digilent/TUL 相关 IP，来源许可保留。
本次没有重新运行这两个 HLS C 源的导出，不能把旧导出报告称作本次 HLS 验证。

## 采集与所有权

1. ARM 分配两块可缓存的 720×1280×32bit CMA，地址需 64 字节对齐。分配后先 flush，CPU 视图保持只读；每次 PL 完成后 invalidate，再读取该帧。
2. 每次只显式提交一块缓冲地址；DMA 从下一次 SOF 开始写，16 beat / 32bit 的 INCR burst 不跨 4KiB。
3. HREF 检查字节成对和宽度；行数在下一次 VSYNC 确认，额外像素/行也会判为坏帧。
4. 最后一个像素的 AXI B 响应成功且收到正确帧结束令牌，才置 done、递增 frame_id。
5. FIFO 满时传感器无法暂停；丢弃余下帧。缺令牌/不完整帧最终被后续 SOF 拒绝或由软件超时复位。
6. ARM 仅处理完成帧；先提交另一块缓冲，再 invalidate 当前帧。采集与显示均保留连续 BGRX32 布局，官方 pixel_unpack 丢弃填充字节。冻结时复制完整源帧；CPU 不原地修改 DMA 采集缓冲。
7. 退出/超时关闭采集输入、清空 FIFO 两个时钟域。写入器保留已经提出的 AW、完整发送16拍 W 并等待 B 响应，期间 busy 保持为1；busy 归零后才释放缓冲。不能单独复位活动 AXI 主机，也不能提前 freebuffer；等待超时会保留缓冲并报错。

## 显示与算法

画布左右两半复制同一 ROI，而不是分别截取原图左右两半。保留源宽高比，必要时留黑边。
左侧在 PL 中旁路，右侧应用同一组帧级配置；全屏时处理全幅。
Gamma 表在非活动 bank 写入，commit 后只在被接收的 SOF 切换，禁止 pending 状态覆写。
切换后增加随流水线推进的保护期，旧帧像素完成 Gamma 查表后才允许改写旧 bank；反压时保护计数也冻结。
所有流数据/sideband/行状态在输出反压时冻结；配置在输入 SOF 锁存，不在帧中改变。
均值计算为尾随 3×3/15×15，避免声称实现了中心对称空间核；不足窗口边界不使用未初始化 RAM。
3×3 降噪仅在当前像素与均值相差不超过12级时平滑，保护细字边界；分屏接缝处独立重启水平窗口。
增强器分级寄存灰度乘积、行缓冲读、窗口和、倒数乘积、降噪判定、Gamma/细节项、限幅和输出。
除9和除225使用经过全输入域核对的整数倒数乘法，逐像素结果与参考模型一致；行缓冲用环形行计数，不在关键路径做取模。

ARM 用有效源 ROI（不含 HDMI 黑边）亮度与 BH1750 照度生成 Gamma，带更新限速与时间平滑。
光照缺失时使用图像统计；距离缺失/超量程记空值；不把错误数据作为自动控制输入。
VL53L0X 通过带超时的驱动后台采集，不在主循环中无期限等待。

PYNQ 2.4 的控制口按 HWH 中 `assist_core/s_axi` 绑定；输出专用 VDMA 仅构造 MM2S，
通过带超时的状态轮询等待新显示帧，避免依赖本设计没有实例化的 AXI 中断控制器。
程序提供 static/keys/sensors/colorbars/live 阶段；对焦固件回读失败会记录警告并保留实时显示。
发布包的脚本、固件、bit/HWH 都带 SHA256，启动前校验，避免跨版本混用。

## 验证限制

XSim 覆盖自定义 RTL，不仿真 PS CPU/Linux、真实 DDR 控制器、摄像头模拟特性、镜头/VCM、HDMI 接收显示器。
完整 720p XSim 使用行为级 AXI 存储模型，验证数据/协议，不证明真实 DDR 带宽或板上 FPS。
自定义 RTL 综合不等于完整系统实现。完整系统 BD 校验也不证明时序、DRC 或 HDMI 物理显示。
必须另行完成布局布线、CDC/输入时序审核、静态 HDMI、彩条颜色/方向、真实场景与稳定性测量。

## 寄存器（assist_core，基址以 HWH 为准）

| 偏移 | 内容 |
| --- | --- |
| 0x00 | ABI 0x56410300 |
| 0x04 | bit0 采集域使能；0 清空采集/FIFO，并要求写入器完成在途事务后停止 |
| 0x08 / 0x0c | 默认宽1280 / 高720 |
| 0x10 / 0x14 | 目的物理地址 / bit0 启动单帧 |
| 0x18 | bit0 busy、bit1 done、bit2 error |
| 0x1c / 0x20 | 正确完成帧序号 / DMA 错误次数 |
| 0x24 / 0x28 / 0x2c | VSYNC 次数 / 溢出帧数 / 格式异常帧数 |
| 0x30 / 0x34 | 阅读配置 / 显示输入 SOF 次数 |
| 0x38 | [3:0] 板载按键，[8:4] 上下左右中，归一为按下=1 |
| 0x3c | bits0..3 两路总线的SCL/SDA释放=1，bit4 RESET_N，bit5 PWDN |
| 0x40 | bits0..3 两路总线实际输入采样 |
| 0x44 | bits7:0 LUT index，15:8 value，写非活动 bank |
| 0x48 / 0x4c | bit0 commit / bit0 pending、bit1 当前 bank |

0x30：[2:0]模式、[3]分屏、[4]降噪、[5]锐化、[7:6]局部强度、[15:8]二值化偏移C。
