# 2026-10-17 增强版首次实板验证

本次在用户的 PYNQ-Z2 上完成基础功能验证，使用 OV5640、GY-302/BH1750、八针无源五向按键和板载 BTN0～BTN3。
显示器接 HDMI OUT。画面与光学对焦结论来自本次聊天中用户的明确观察确认；计数、读数和固件校验来自板端日志。

## 后续如何启动

开发板重启后，在 Jupyter 的 New → Terminal 中运行：

```bash
cd /home/xilinx/jupyter_notebooks/visual_aid_v3_enhanced
sudo /usr/bin/python3 run_board.py --stage live --no-distance --af continuous --io-confirmed
```

首次使用或改线后，应先按 `docs/board_bringup_zh.md` 核对接线与电压条件。
每次运行的 AF 固件上传与完整回读，本次实测约 47 秒，随后才开始显示实景。
上述前台启动方式用 Ctrl+C 结束。不要在当前后台演示尚在运行时同时启动另一份图像程序。

以下为此次停止后台演示时采用的方法；PID 2932 目前已经退出，无需再次执行。
停止后台程序前，先在 Jupyter Terminal 中核对进程：

```bash
ps -p 2932 -o pid,args
```

确认显示本目录的 `run_board.py` 后，执行 `sudo kill -INT 2932`，等待其写完报告并退出，再运行其他测试。
开发板重启后 PID 会变化，届时使用前台启动与 Ctrl+C 即可。
