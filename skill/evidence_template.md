# 验证记录模板

项目/版本：待填写。主机日期及板端日期：分别填写。板卡、工具、bit/HWH/软件 SHA-256：分别填写。

| 指标 | 条件 | 实际结果 | 原始文件 | 结论范围 |
|---|---|---|---|---|
| 软件测试 | Python/依赖版本、测试命令 | 数量与 PASS/FAIL | 完整日志 | 主机逻辑 |
| RTL 仿真 | 分辨率/帧数/随机种子/参考算法 | 逐像素及协议断言 | 输入/参考/输出/日志 | 仿真覆盖 |
| 综合布线 | 器件/时钟/约束/策略 | 资源、setup/hold、DRC | 工具报告 | 指定约束下实现 |
| 板端运行 | 时长/场景/操作/温度 | 帧率和错误增量 | 原始 JSON | 此次有限运行 |
| 物理观察 | 显示/运动/旋钮/光照 | 观察者原话 | 单独观察记录 | 观察到的功能 |

未测项目：明确列出；不要填 0 或 PASS。失败保留：触发、原始错误、修改、重跑结果。严格 A/B 需相同硬件/输入/设置、重复次数和离散度，否则只写历史趋势。
